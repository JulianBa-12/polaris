# Polaris Client – Community

Website und Community-Daten des Polaris Client für Kirka.io, gehostet mit GitHub Pages:
https://julianba-12.github.io/polaris/

- `api/*.json` – öffentliche Community-Daten (Profile, Abzeichen, Ankündigungen, Status, Downloads). Werden vom Polaris Owner Client automatisch aktualisiert – bitte nicht von Hand bearbeiten.
- `files/` – hochgeladene Bilder (Profil-Hintergründe, Abzeichen)
- `updates/stable/latest-linux.yml` – Update-Quelle der Clients, die Installer liegen unter Releases
- `data/db.json` – Datenstand für den Owner Client (ohne Konten)
